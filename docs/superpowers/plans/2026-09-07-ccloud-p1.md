# ccloud P1 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付 ccloud 微服务平台的地基：BOM、16 个 framework starter、网关、监控、system 模块全量、member 用户与认证、全部 10 个模块的完整数据库脚本、Docker 编排、README 与 MIT LICENSE —— 结束时三端可登录、动态菜单与按钮权限生效、SSO 跑通、Swagger 网关聚合可调。

**Architecture:** 单库多租户行级隔离的 Spring Cloud 微服务。网关统一校验 OAuth2 令牌并以 HMAC 签名内部头下发身份，业务服务不重复查库。框架能力全部 starter 化，业务模块拆 `-api`（DTO+Feign）与 `-biz`（实现），`-biz` 不被任何模块依赖，保证可整体裁剪。

**Tech Stack:** JDK 21、Spring Boot 3.5.16、Spring Cloud 2025.0.3、Spring Cloud Alibaba 2025.0.0.0、Nacos 3.2.4、MyBatis Plus 3.5.17、MySQL 8.4、Redis 7 + Redisson、springdoc 2.9.1 + Knife4j 4.5.0、XXL-Job 3.4.2、Sentinel、Micrometer Tracing + Zipkin、Spring Boot Admin。

**Spec:** `docs/superpowers/specs/2026-09-07-ccloud-design.md`

## Global Constraints

以下取值为全局硬约束，每个任务的验收条件都隐含包含本节。

- **JDK 21**，`maven.compiler.release=21`，源码文件编码 UTF-8。
- **版本唯一仲裁点是 `ccloud-dependencies/pom.xml`**。任何子模块 pom 中出现 `<version>` 均视为缺陷，除非该依赖不在 BOM 中（此时必须先加进 BOM）。
- **根包名 `com.ccloud`**。framework 层 `com.ccloud.framework.<能力>`，业务层 `com.ccloud.module.<模块>`，网关 `com.ccloud.gateway`。
- **数据库名 `ccloud`**，字符集 `utf8mb4`，排序规则 `utf8mb4_0900_ai_ci`，存储引擎 InnoDB。
- **接口路径前缀写死在 Controller 上，网关不做 StripPrefix**：管理端 `/admin-api/**`、用户端 `/app-api/**`、开放 `/open-api/**`、内部 `/rpc-api/**`。服务单独启动与经网关访问的路径完全一致。
- **Nacos 服务名**：`ccloud-gateway`、`ccloud-system-server`、`ccloud-infra-server`、`ccloud-member-server`、`ccloud-open-server`、`ccloud-pay-server`、`ccloud-bpm-server`、`ccloud-product-server`、`ccloud-trade-server`、`ccloud-promotion-server`、`ccloud-ai-server`、`ccloud-monitor`。
- **端口**：gateway 48080、system 48081、infra 48082、member 48083、open 48084、pay 48085、bpm 48086、product 48087、trade 48088、promotion 48089、ai 48090；XXL-Job Admin 48180、Sentinel Dashboard 48181、Spring Boot Admin 48182；MySQL 3306、Redis 6379、Nacos 8848/9848、Zipkin 9411。

- **所有密码用 BCrypt**（`BCryptPasswordEncoder`，强度 4，与参考项目一致以便本地快速登录）。
- **License 头**：不在源码文件加版权头；仓库根 `LICENSE` 为 MIT 全文，各 pom 声明 `<licenses><license><name>MIT License</name>`。
- **提交信息用中文 + Conventional Commits 前缀**（`feat: / fix: / chore: / docs: / test:`），不加任何署名行。

**内部身份头协议**（网关 ↔ 业务服务，Task 42 与 Task 7 的实现必须逐字一致）：

| Header | 内容 |
|---|---|
| `X-Login-User` | `Base64(UTF8(JSON(LoginUser)))` |
| `X-Login-User-Sign` | `Base64(HmacSHA256(secret, X-Login-User 的值 + "." + X-Timestamp))` |
| `X-Timestamp` | 毫秒时间戳，业务侧校验 ±5 分钟 |
| `X-Tenant-Id` | 租户 ID，冗余便于日志 |

`secret` 取自配置 `ccloud.security.internal-sign-secret`，通过 Nacos 共享配置下发。网关在写入前**必须先移除**请求中同名的外部头。

  creator     varchar(64)  DEFAULT ''  COMMENT '创建者',
