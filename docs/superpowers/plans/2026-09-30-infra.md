# 基础设施模块实施计划（P2 第 2 项）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 新建 `ccloud-module-infra` 服务（端口 28082），交付参数配置、文件存储（数据库 / 本地磁盘 / S3 兼容）、API 访问与异常日志、消息死信、数据源、数据库文档、代码生成（单表 + 树表），并把 system / member 中等待 infra 的初始密码、注册开关、头像上传接上。

**Architecture:** infra 的结构与 member 一致（`infra-api` 放错误码、枚举与 Feign 接口，`infra-biz` 为可执行应用），权限、租户等五个框架契约经 RPC 由 system 实现。其他服务读参数、存头像走 `ConfigApi` / `FileApi`；API 日志由各服务经 Redis Stream 发给 infra 写库。代码生成用 Velocity 渲染本项目风格的后端代码，由 `scripts/verify-codegen.sh` 在临时工作区里真实编译并运行生成的测试来验收。

**Tech Stack:** JDK 21、Spring Boot 3.5.16、MyBatis Plus 3.5.17、MySQL 8.4、Redis 8；Apache Tika（内容识别文件类型）、AWS SDK v2（S3）、Velocity 2.4.1（代码模板）；测试用 JUnit 5 + AssertJ + MockMvc，连接本机已有的 MySQL（`ccloud_test` 库）、Redis（15 号库）与 MinIO。

**Spec:** `docs/superpowers/specs/2026-09-30-infra-design.md`

## Global Constraints

每个任务的验收条件都隐含包含本节。

- 分支 `feat/p2-infra-member-open`，只在该分支提交，不推送。
- 构建默认离线：`mvn -o`。**新增依赖（Tika 3.3.2、AWS SDK）首次需去掉 `-o` 联网下载一次**，之后恢复离线。单模块测试加 `-am`，例如 `mvn -o -q -pl ccloud-module-infra/ccloud-module-infra-biz -am test -Dtest=XxxTest -Dsurefire.failIfNoSpecifiedTests=false`。安静模式下测试通过时没有输出，结果看 `target/surefire-reports/TEST-*.xml`。
- 路径前缀写在 Controller 上：管理端 `/admin-api/infra/**`，用户端 `/app-api/infra/**`，内部 `/rpc-api/infra/**`（由 `infra-api` 的 Feign 接口定义）。
- 管理端接口用 `@PreAuthorize("@ss.hasPermission('...')")`，权限标识取自 `sql/mysql/dml/02-menu.sql` 已登记的按钮，不新增菜单。
- DO 的注解与 `MemberTagDO` 一致（`@TableName`、`@Data`、`@EqualsAndHashCode(callSuper = true)`、`@ToString(callSuper = true)`、`@Accessors(chain = true)`，主键 `@TableId`）。按租户隔离的表继承 `TenantBaseDO`，全局表继承 `BaseDO`，不手工赋值 `tenantId`（日志消费除外，见 Task 10）。
- Web 集成测试不回滚事务，数据会提交到共享的测试库：测试数据一律带可识别的前缀（参数键 `webtest.`、文件配置名 `Web测试`、数据源名 `Web测试`），并在 `@AfterEach` 中删除。
- 错误码在 `ErrorCodeConstants` 定义，并在 `sql/mysql/dml/06-i18n.sql` 登记中英文文案；改了 `dml/` 或 `ddl/` 后执行 `scripts/build-sql.sh` 重新生成 `sql/mysql/ccloud.sql`。
- 先写测试再实现；每个任务结束前，对关键逻辑做变异检查：改坏代码，确认有测试失败，再还原。还原后必须 `touch` 被还原的文件，否则 Maven 会沿用改坏时编译出的 class。
- 提交信息用中文 + Conventional Commits 前缀，不加署名行。
- 与用户沟通一律用中文。
- 测试与校验脚本连接本机已有的中间件（见 `LocalMySql` / `LocalRedis`、`scripts/lib/local-middleware.sh`），不临时启动容器；缺少中间件时先问用户，装了不删。**MinIO 只能在 Task 8 征得用户同意后安装。**
- XXL-Job 调度中心端口保持 48180，不做调整。

```java
// {iapi}/api/config/ConfigApi.java
@FeignClient(name = ApiConstants.NAME, contextId = "infraConfigApi")
@Tag(name = "RPC 服务 - 参数配置")
public interface ConfigApi {
    String PREFIX = ApiConstants.PREFIX + "/config";

    @GetMapping(PREFIX + "/get-value-by-key")
    @Operation(summary = "根据参数键查询参数值", description = "参数不存在时返回 null；内部调用不区分是否可见")
    CommonResult<String> getConfigValueByKey(@RequestParam("key") String key);
}

// {iapi}/api/file/FileApi.java
@FeignClient(name = ApiConstants.NAME, contextId = "infraFileApi")
@Tag(name = "RPC 服务 - 文件")
public interface FileApi {
    String PREFIX = ApiConstants.PREFIX + "/file";

    @PostMapping(PREFIX + "/create")
    @Operation(summary = "保存文件", description = "按主配置存储，返回访问地址；类型与大小的限制与上传接口相同")
    CommonResult<String> createFile(@Valid @RequestBody FileCreateReqDTO reqDTO);
}

// {iapi}/api/file/dto/FileCreateReqDTO.java：String name（原始文件名，可空）、byte[] content（@NotEmpty）
```

```java
@Service
@Validated
public class ConfigServiceImpl implements ConfigService {

    @Resource
    private ConfigMapper configMapper;

    @Override
    @CacheEvict(cacheNames = RedisKeyConstants.CONFIG, allEntries = true)
    public Long createConfig(ConfigSaveReqVO reqVO) {
        validateConfigKeyUnique(null, reqVO.getKey());
        ConfigDO config = toDO(reqVO).setType(ConfigTypeEnum.CUSTOM.getType());
        configMapper.insert(config);
        return config.getId();
    }

    @Override
    @CacheEvict(cacheNames = RedisKeyConstants.CONFIG, allEntries = true)
    public void updateConfig(ConfigSaveReqVO reqVO) {
        ConfigDO old = validateConfigExists(reqVO.getId());
        // 系统内置参数的键名被代码引用，改了就等于删除
        if (ConfigTypeEnum.SYSTEM.getType().equals(old.getType()) && !old.getConfigKey().equals(reqVO.getKey())) {
            throw exception(CONFIG_KEY_CAN_NOT_UPDATE_SYSTEM_TYPE);
        }
        validateConfigKeyUnique(reqVO.getId(), reqVO.getKey());
        configMapper.updateById(toDO(reqVO).setType(null));
    }

    @Override
    @CacheEvict(cacheNames = RedisKeyConstants.CONFIG, allEntries = true)
    public void deleteConfig(Long id) {
        ConfigDO config = validateConfigExists(id);
        if (ConfigTypeEnum.SYSTEM.getType().equals(config.getType())) {
            throw exception(CONFIG_CAN_NOT_DELETE_SYSTEM_TYPE);
        }
        configMapper.deleteById(id);
    }

    @Override
    public ConfigDO getConfig(Long id) {
        return configMapper.selectById(id);
    }

    @Override
    @Cacheable(cacheNames = RedisKeyConstants.CONFIG, key = "#key", unless = "#result == null")
    public ConfigDO getConfigByKey(String key) {
        return configMapper.selectByKey(key);
    }

    @Override
    public PageResult<ConfigDO> getConfigPage(ConfigPageReqVO reqVO) {
        return configMapper.selectPage(reqVO);
    }

    private ConfigDO validateConfigExists(Long id) {
        ConfigDO config = id == null ? null : configMapper.selectById(id);
        if (config == null) {
            throw exception(CONFIG_NOT_EXISTS);
        }
        return config;
    }

    private void validateConfigKeyUnique(Long id, String key) {
        ConfigDO config = configMapper.selectByKey(key);
        if (config != null && !config.getId().equals(id)) {
            throw exception(CONFIG_KEY_DUPLICATE);
        }
    }

    private static ConfigDO toDO(ConfigSaveReqVO reqVO) {
        return BeanUtils.toBean(reqVO, ConfigDO.class).setConfigKey(reqVO.getKey());
    }
}
```

```java
public class LocalFileClient extends AbstractFileClient<LocalFileClientConfig> {

    private final Path basePath;

    public LocalFileClient(Long id, LocalFileClientConfig config) {
        super(id, config);
        this.basePath = Paths.get(config.getBasePath()).toAbsolutePath().normalize();
    }

    @Override
    public String upload(byte[] content, String path, String type) throws IOException {
        Path file = resolve(path);
        if (!Files.exists(file)) {
            Files.createDirectories(file.getParent());
            Files.write(file, content);
        }
        return formatFileUrl(path);
    }

    @Override
    public void delete(String path) throws IOException {
        Files.deleteIfExists(resolve(path));
    }

    @Override
    public byte[] getContent(String path) throws IOException {
        Path file = resolve(path);
        return Files.isRegularFile(file) ? Files.readAllBytes(file) : null;
    }

    /**
     * 规范化后必须仍在根目录内：路径来自 URL，不校验就能用 ../ 读写服务器上的任意文件
     */
    private Path resolve(String path) {
        Path file = basePath.resolve(path).normalize();
        if (StrUtil.isBlank(path) || Paths.get(path).isAbsolute() || !file.startsWith(basePath) || file.equals(basePath)) {
            throw exception(FILE_PATH_INVALID);
        }
        return file;
    }
}
```

```java
public class FileClientFactory {

    private final ConcurrentMap<Long, FileClient> clients = new ConcurrentHashMap<>();

    @Resource
    private FileConfigMapper fileConfigMapper;
    @Resource
    private FileContentMapper fileContentMapper;

    public FileClient getFileClient(Long configId) {

            FileConfigDO config = fileConfigMapper.selectById(id);
            if (config == null) {

            }
            return createClient(config);

    public void invalidateAll() {

        FileStorageEnum storage = FileStorageEnum.valueOf(config.getStorage());
```

```java
    public Long createFileConfig(FileConfigSaveReqVO reqVO) {
        FileClientConfig config = parseConfig(reqVO.getStorage(), reqVO.getConfig(), null);
        FileConfigDO fileConfig = new FileConfigDO().setName(reqVO.getName()).setStorage(reqVO.getStorage())
                .setRemark(reqVO.getRemark()).setConfig(JsonUtils.toJsonString(config))
                // 没有主配置时第一条自动成为主配置，否则上传会失败

    /**
     * 按存储器解析并校验配置。提交的密钥为掩码时沿用原值：前端拿到的就是掩码，原样提交不应清空密钥
     */
    FileClientConfig parseConfig(Integer storage, Map<String, Object> config, FileConfigDO old) {
        FileStorageEnum storageEnum = FileStorageEnum.valueOf(storage);
        if (storageEnum == null) {
            throw exception(FILE_CONFIG_INVALID, "不支持的存储器 " + storage);
        }
        Map<String, Object> merged = new HashMap<>(config);
        if (old != null && storage.equals(old.getStorage())) {
            Map<String, Object> oldConfig = JsonUtils.parseObject(old.getConfig(), new TypeReference<>() {});
            for (String key : storageEnum.getSecretKeys()) {
                if (DesensitizeUtils.MASK.equals(merged.get(key))) {
                    merged.put(key, oldConfig.get(key));
                }
            }
        }
        FileClientConfig parsed = JsonUtils.parseObject(JsonUtils.toJsonString(merged), storageEnum.getConfigClass());
        Set<ConstraintViolation<FileClientConfig>> violations = validator.validate(parsed);
        if (!violations.isEmpty()) {
            throw exception(FILE_CONFIG_INVALID, violations.iterator().next().getMessage());
        }
        return parsed;
    }
```

```java
import org.apache.tika.Tika;

import java.util.Map;

/**
 * 按内容识别文件类型，只放行白名单。
 *
 * <p>扩展名与请求头里的类型都由上传者决定，不可信；网页、SVG、XML、脚本即使改名也会被识别出来并拒绝，
 * 否则上传的文件经我们的域名输出，就成了存储型 XSS 的载体

public final class FileTypeUtils {

    private static final Tika TIKA = new Tika();

    /**
     * 允许上传的类型 → 保存时使用的扩展名
     */
    private static final Map<String, String> ALLOWED = Map.ofEntries(
            Map.entry("image/jpeg", "jpg"), Map.entry("image/png", "png"), Map.entry("image/gif", "gif"),
            Map.entry("image/webp", "webp"), Map.entry("image/bmp", "bmp"),
            Map.entry("application/pdf", "pdf"),
            Map.entry("application/msword", "doc"),
            Map.entry("application/vnd.openxmlformats-officedocument.wordprocessingml.document", "docx"),
            Map.entry("application/vnd.ms-excel", "xls"),
            Map.entry("application/vnd.openxmlformats-officedocument.spreadsheetml.sheet", "xlsx"),
            Map.entry("application/vnd.ms-powerpoint", "ppt"),
            Map.entry("application/vnd.openxmlformats-officedocument.presentationml.presentation", "pptx"),
            Map.entry("application/zip", "zip"),
            Map.entry("text/plain", "txt"), Map.entry("text/csv", "csv"),
            Map.entry("audio/mpeg", "mp3"), Map.entry("video/mp4", "mp4"));

    public record FileType(String mimeType, String extension) {
    }

    private FileTypeUtils() {
    }

    /**
     * @param name 原始文件名，只作为同类格式的细分依据（如 zip 与 docx），可为空
     * @return 白名单内的类型；不在白名单返回 null
     */
    public static FileType detect(byte[] content, String name) {
        String mimeType = TIKA.detect(content, name);
        String extension = ALLOWED.get(mimeType);
        return extension != null ? new FileType(mimeType, extension) : null;
    }

    public static boolean isInline(String mimeType) {
        return mimeType != null && (mimeType.startsWith("image/") || mimeType.equals("application/pdf"));
    }
```

```java
@Service
@Slf4j
public class FileServiceImpl implements FileService {

    @Resource
    private FileMapper fileMapper;
    @Resource
    private FileClientFactory fileClientFactory;
    @Resource
    private FileProperties fileProperties;

    @Override
    public String createFile(String name, byte[] content) {
        if (content == null || content.length == 0) {
            throw exception(FILE_EMPTY);
        }
        if (content.length > fileProperties.getMaxSize().toBytes()) {
            throw exception(FILE_SIZE_EXCEEDED, fileProperties.getMaxSize());
        }
        FileTypeUtils.FileType type = FileTypeUtils.detect(content, name);
        if (type == null) {
            throw exception(FILE_TYPE_NOT_ALLOWED, FileTypeUtils.detectMimeType(content, name));
        }
        // 按内容哈希命名：同一存储里相同内容只存一份，路径也无法按顺序猜出
        String path = DateUtil.format(new Date(), "yyyyMMdd") + "/" + DigestUtil.sha256Hex(content) + "." + type.extension();
        FileClient client = fileClientFactory.getMasterFileClient();
        String url;
        try {
            url = client.upload(content, path, type.mimeType());
        } catch (ServiceException e) {
            throw e;
        } catch (Exception e) {
            log.error("[createFile][配置 {} 存储 {} 失败]", client.getId(), path, e);
            throw exception(FILE_UPLOAD_FAILED, e.getMessage());
        }
        fileMapper.insert(new FileDO().setConfigId(client.getId()).setName(StrUtil.maxLength(name, 250))
                .setPath(path).setUrl(url).setType(type.mimeType()).setSize(content.length));
        return url;
    }

    @Override
    public void deleteFile(Long id) {
        FileDO file = fileMapper.selectById(id);
        if (file == null) {
            throw exception(FILE_NOT_EXISTS);
        }
        fileMapper.deleteById(id);
        // 相同内容可能被其他租户的记录引用，计数时忽略租户
        Long refs = TenantUtils.executeIgnore(() -> fileMapper.selectCountByConfigIdAndPath(file.getConfigId(), file.getPath()));
        if (refs > 0) {
            return;
        }
        try {
            fileClientFactory.getFileClient(file.getConfigId()).delete(file.getPath());
        } catch (Exception e) {
            // 记录已删除，存储中的内容残留不影响使用，打日志后人工清理
            log.warn("[deleteFile][配置 {} 删除 {} 失败]", file.getConfigId(), file.getPath(), e);
        }
    }

    @Override
    public byte[] getFileContent(Long configId, String path) {
        try {
            return fileClientFactory.getFileClient(configId).getContent(path);
        } catch (ServiceException e) {
            throw e;
        } catch (Exception e) {
            log.error("[getFileContent][配置 {} 读取 {} 失败]", configId, path, e);
            return null;
        }
    }
}
```

```java
    @GetMapping("/{configId}/get/**")
    @Operation(summary = "读取文件", description = "免登录；数据库与本地磁盘存储的文件经此输出")
    @ApiAccessLog(enable = false)
    public void getFileContent(HttpServletRequest request, HttpServletResponse response,
                               @PathVariable("configId") Long configId) throws IOException {
        String path = StrUtil.subAfter(URLUtil.decode(request.getRequestURI()), "/get/", false);
        byte[] content = StrUtil.isBlank(path) || path.contains("..") ? null : fileService.getFileContent(configId, path);
        if (content == null) {
            response.setStatus(HttpStatus.NOT_FOUND.value());
            return;
        }
        FileTypeUtils.FileType type = FileTypeUtils.detect(content, path);
        String mimeType = type != null ? type.mimeType() : MediaType.APPLICATION_OCTET_STREAM_VALUE;
        response.setContentType(mimeType);
        response.setHeader("X-Content-Type-Options", "nosniff");
        // 路径含内容哈希，内容不会变，可以长期缓存
        response.setHeader(HttpHeaders.CACHE_CONTROL, "public, max-age=31536000, immutable");
        response.setHeader(HttpHeaders.CONTENT_DISPOSITION, ContentDisposition
                .builder(FileTypeUtils.isInline(mimeType) ? "inline" : "attachment")
                .filename(FileUtil.getName(path), StandardCharsets.UTF_8).build().toString());
        response.setContentLength(content.length);
        response.getOutputStream().write(content);
    }
```

```java
public class S3FileClient extends AbstractFileClient<S3FileClientConfig> {

    private final S3Client s3;

    public S3FileClient(Long id, S3FileClientConfig config) {
        super(id, config);
        this.s3 = S3Client.builder()
                .endpointOverride(URI.create(config.getEndpoint()))
                .region(Region.of(StrUtil.blankToDefault(config.getRegion(), "us-east-1")))
                .credentialsProvider(StaticCredentialsProvider.create(
                        AwsBasicCredentials.create(config.getAccessKey(), config.getAccessSecret())))
                .serviceConfiguration(S3Configuration.builder()
                        .pathStyleAccessEnabled(Boolean.TRUE.equals(config.getPathStyle())).build())
                // 新版 SDK 默认附加 CRC 校验头，部分 S3 兼容存储不认，只在服务端要求时计算
                .requestChecksumCalculation(RequestChecksumCalculation.WHEN_REQUIRED)
                .responseChecksumValidation(ResponseChecksumValidation.WHEN_REQUIRED)
                .httpClient(UrlConnectionHttpClient.create())
                .build();
    }

    @Override
    public String upload(byte[] content, String path, String type) {
        s3.putObject(PutObjectRequest.builder().bucket(config.getBucket()).key(path).contentType(type).build(),
                RequestBody.fromBytes(content));
        return StrUtil.removeSuffix(config.getDomain(), "/") + "/" + path;
    }

    @Override
    public void delete(String path) {
        s3.deleteObject(DeleteObjectRequest.builder().bucket(config.getBucket()).key(path).build());
    }

    @Override
    public byte[] getContent(String path) {
        try {
            return s3.getObjectAsBytes(GetObjectRequest.builder().bucket(config.getBucket()).key(path).build()).asByteArray();
        } catch (NoSuchKeyException e) {
            return null;
        }
    }

    /**
     * 仅供测试：存储桶不存在时创建，并设置匿名只读策略
     */
    void createBucketIfAbsentForTest() {
        try {
            s3.headBucket(HeadBucketRequest.builder().bucket(config.getBucket()).build());
        } catch (NoSuchBucketException e) {
            s3.createBucket(CreateBucketRequest.builder().bucket(config.getBucket()).build());
        }
        String policy = """
                {"Version":"2012-10-17","Statement":[{"Effect":"Allow","Principal":{"AWS":["*"]},
                "Action":["s3:GetObject"],"Resource":["arn:aws:s3:::%s/*"]}]}""".formatted(config.getBucket());
        s3.putBucketPolicy(PutBucketPolicyRequest.builder().bucket(config.getBucket()).policy(policy).build());
    }
}
```

```java
    public static Object desensitize(Object value) {
        return desensitize(value, Collections.emptySet());
    }

    /**
     * @param extraKeys 调用方额外指定的敏感字段名，精确匹配、不区分大小写
     */
    public static Object desensitize(Object value, Collection<String> extraKeys) {
        if (value == null) {
            return null;
        }
        Set<String> extra = extraKeys.stream().map(k -> k.toLowerCase(Locale.ROOT)).collect(Collectors.toSet());
        JsonNode node = value instanceof JsonNode json ? json.deepCopy() : JsonUtils.getObjectMapper().valueToTree(value);
        mask(node, extra);
        return node;
    }

    private static void mask(JsonNode node, Set<String> extra) {
        if (node.isObject()) {
            Iterator<Map.Entry<String, JsonNode>> fields = node.fields();
            while (fields.hasNext()) {
                Map.Entry<String, JsonNode> field = fields.next();
                if (SENSITIVE_KEY.matcher(field.getKey()).matches() || extra.contains(field.getKey().toLowerCase(Locale.ROOT))) {
                    ((ObjectNode) node).put(field.getKey(), MASK);
                } else {
                    mask(field.getValue(), extra);
                }
            }
        } else if (node.isArray()) {
            node.forEach(child -> mask(child, extra));
        }
    }
```

```java
package com.ccloud.framework.apilog.core.util;

/**
 * 访问日志与异常日志共用的参数整理：脱敏后序列化，截断到列宽
 */
public final class ApiLogUtils {

    public static final int MAX_LENGTH = 8000;

    private ApiLogUtils() {
    }

    public static String buildRequestParams(Map<String, String> query, String body, Collection<String> extraKeys) {
        Map<String, Object> params = new LinkedHashMap<>();
        params.put("query", DesensitizeUtils.desensitize(query, extraKeys));
        if (body != null) {
            params.put("body", parseBody(body, extraKeys));
        }
        return StrUtil.maxLength(JsonUtils.toJsonString(params), MAX_LENGTH);
    }

    public static String buildResponseBody(Object result, Collection<String> extraKeys) {
        return result == null ? null
                : StrUtil.maxLength(JsonUtils.toJsonString(DesensitizeUtils.desensitize(result, extraKeys)), MAX_LENGTH);
    }

    /**
     * 解析不了的请求体不能原样落库：无法判断其中哪些是密码
     */
    private static Object parseBody(String body, Collection<String> extraKeys) {
        if (StrUtil.isBlank(body)) {
            return null;
        }
        try {
            return DesensitizeUtils.desensitize(JsonUtils.getObjectMapper().readTree(body), extraKeys);
        } catch (JsonProcessingException e) {
            return "<无法解析的请求体，长度 " + body.length() + ">";
        }
    }
}
```

```java
    private static HandlerMethod getHandlerMethod(HttpServletRequest request) {
        Object handler = request.getAttribute(HandlerMapping.BEST_MATCHING_HANDLER_ATTRIBUTE);
        return handler instanceof HandlerMethod method ? method : null;
    }

    private static ApiAccessLog getAnnotation(HandlerMethod handler) {
        ApiAccessLog annotation = handler.getMethodAnnotation(ApiAccessLog.class);
        return annotation != null ? annotation : handler.getBeanType().getAnnotation(ApiAccessLog.class);
    }

    /**
     * 模块名、操作名优先取注解，其次取接口文档注解，便于在日志里按业务检索
     */
    private static void fillOperate(com.ccloud.framework.apilog.core.service.ApiAccessLog accessLog,
                                    HandlerMethod handler, ApiAccessLog annotation) {
        if (handler == null) {
            return;
        }
        Tag tag = handler.getBeanType().getAnnotation(Tag.class);
        Operation operation = handler.getMethodAnnotation(Operation.class);
        String module = annotation != null ? annotation.operateModule() : "";
        String name = annotation != null ? annotation.operateName() : "";
        accessLog.setOperateModule(StrUtil.maxLength(StrUtil.blankToDefault(module, tag != null ? tag.name() : null), 50));
        accessLog.setOperateName(StrUtil.maxLength(StrUtil.blankToDefault(name, operation != null ? operation.summary() : null), 50));
        if (annotation != null) {
            accessLog.setOperateType(annotation.operateType().getType());
```

```java
        log.setTenantId(ObjectUtil.defaultIfNull(accessLog.getTenantId(), 0L));
        log.setUserId(ObjectUtil.defaultIfNull(log.getUserId(), 0L));

        log.setUserAgent(StrUtil.maxLength(StrUtil.nullToEmpty(log.getUserAgent()), 512));
        log.setApplicationName(StrUtil.maxLength(StrUtil.nullToEmpty(log.getApplicationName()), 50));
        log.setResultMsg(StrUtil.maxLength(StrUtil.nullToEmpty(log.getResultMsg()), 512));
        TenantUtils.executeIgnore(() -> apiAccessLogMapper.insert(log));
    }

    @Override
    public int cleanApiAccessLog(int retainDays, int batchSize) {

            total += deleted;
        } while (deleted >= batchSize);
        return total;
    }
```

```java
/**
 * API 访问日志与异常日志经 Redis Stream 发给 infra 写库。
 *
 * <p>单线程有界队列异步发送：日志不能拖慢业务请求；Redis 故障或积压时丢弃并打警告，不影响业务
 */
@Slf4j
@Component
public class ApiLogFrameworkServiceImpl implements ApiAccessLogFrameworkService, ApiErrorLogFrameworkService,
        DisposableBean {

    private final MessageSender messageSender;
    private final ThreadPoolExecutor executor = new ThreadPoolExecutor(1, 1, 0, TimeUnit.MILLISECONDS,
            new ArrayBlockingQueue<>(10_000), r -> {
                Thread thread = new Thread(r, "api-log-sender");
                thread.setDaemon(true);
                return thread;
            }, (r, e) -> log.warn("[api-log] 发送队列已满，丢弃一条日志"));

    public ApiLogFrameworkServiceImpl(@Lazy MessageSender messageSender) {
        this.messageSender = messageSender;
    }

    @Override
    public void createApiAccessLogAsync(ApiAccessLog accessLog) {
        send(ApiLogTopics.ACCESS_LOG, accessLog);
    }

    @Override
    public void createApiErrorLogAsync(ApiErrorLog errorLog) {
        send(ApiLogTopics.ERROR_LOG, errorLog);
    }

    private void send(String topic, Object payload) {
        executor.execute(() -> {
            try {
                messageSender.send(topic, IdUtil.fastSimpleUUID(), JsonUtils.toJsonString(payload));
            } catch (RuntimeException e) {
                log.warn("[api-log] 发送到 {} 失败，丢弃", topic, e);
            }
        });
    }

    @Override
    public void destroy() throws InterruptedException {
        executor.shutdown();
        executor.awaitTermination(5, TimeUnit.SECONDS);
    }
}
```

```java
@Service
public class MessageDeadLetterServiceImpl implements MessageDeadLetterService {

    @Resource
    private DeadLetterMapper deadLetterMapper;
    @Resource
    private MessageSender messageSender;

    @Override
    @TenantIgnore
    public PageResult<DeadLetterDO> getDeadLetterPage(MessageDeadLetterPageReqVO reqVO) {
        return deadLetterMapper.selectPage(reqVO, new LambdaQueryWrapperX<DeadLetterDO>()
                .likeIfPresent(DeadLetterDO::getTopic, reqVO.getTopic())
                .eqIfPresent(DeadLetterDO::getMessageId, reqVO.getMessageId())
                .eqIfPresent(DeadLetterDO::getHandled, reqVO.getHandled())
                .betweenIfPresent(DeadLetterDO::getCreateTime, reqVO.getCreateTime())
                .orderByDesc(DeadLetterDO::getId));
    }

    @Override
    @TenantIgnore
    public void updateDeadLetterHandled(Long id) {
        validateUnhandled(id);
        markHandled(id);
    }

    /**
     * 沿用原消息编号：消费方按编号幂等，已成功消费过的下游不会重复执行业务
     */
    @Override
    @TenantIgnore
    public void resendDeadLetter(Long id) {
        DeadLetterDO deadLetter = validateUnhandled(id);
        messageSender.send(deadLetter.getTopic(), deadLetter.getMessageId(), deadLetter.getPayload());
        markHandled(id);
    }

    private DeadLetterDO validateUnhandled(Long id) {
        DeadLetterDO deadLetter = deadLetterMapper.selectById(id);
        if (deadLetter == null) {
            throw exception(MESSAGE_DEAD_LETTER_NOT_EXISTS);
        }
        if (Boolean.TRUE.equals(deadLetter.getHandled())) {
            throw exception(MESSAGE_DEAD_LETTER_HANDLED);
        }
        return deadLetter;
    }

    private void markHandled(Long id) {
        DeadLetterDO update = new DeadLetterDO();
        update.setId(id);
        update.setHandled(true);
        update.setHandledTime(LocalDateTime.now());
        deadLetterMapper.updateById(update);
    }
}
```

```java
@Service
public class DatabaseTableServiceImpl implements DatabaseTableService {

    private static final String SQL_TABLES = "SELECT TABLE_NAME, TABLE_COMMENT FROM information_schema.TABLES "
            + "WHERE TABLE_SCHEMA = DATABASE() AND TABLE_TYPE = 'BASE TABLE' ORDER BY TABLE_NAME";
    private static final String SQL_COLUMNS = "SELECT TABLE_NAME, COLUMN_NAME, COLUMN_TYPE, DATA_TYPE, COLUMN_COMMENT, "
            + "IS_NULLABLE, COLUMN_DEFAULT, COLUMN_KEY, EXTRA, ORDINAL_POSITION, CHARACTER_MAXIMUM_LENGTH "
            + "FROM information_schema.COLUMNS WHERE TABLE_SCHEMA = DATABASE() %s ORDER BY TABLE_NAME, ORDINAL_POSITION";
    private static final String SQL_INDEXES = "SELECT TABLE_NAME, INDEX_NAME, NON_UNIQUE, COLUMN_NAME "
            + "FROM information_schema.STATISTICS WHERE TABLE_SCHEMA = DATABASE() %s ORDER BY TABLE_NAME, INDEX_NAME, SEQ_IN_INDEX";

    @Resource
    private DataSourceConfigService dataSourceConfigService;

    @Override
    public List<TableInfo> getTableList(Long dataSourceConfigId, String name, String comment) {
        return execute(dataSourceConfigId, conn -> queryTables(conn).stream()
                .filter(t -> StrUtil.isEmpty(name) || StrUtil.containsIgnoreCase(t.name(), name))
                .filter(t -> StrUtil.isEmpty(comment) || StrUtil.containsIgnoreCase(t.comment(), comment))
                .toList());
    }

    @Override
    public TableInfo getTable(Long dataSourceConfigId, String tableName) {
        return execute(dataSourceConfigId, conn -> {
            TableInfo table = CollUtil.findOne(queryTables(conn), t -> t.name().equals(tableName));
            if (table == null) {
                return null;
            }
            return withDetails(List.of(table), queryColumns(conn, tableName), queryIndexes(conn, tableName)).get(0);
        });
    }

    @Override
    public List<TableInfo> getTableListWithDetails(Long dataSourceConfigId) {
        return execute(dataSourceConfigId, conn ->
                withDetails(queryTables(conn), queryColumns(conn, null), queryIndexes(conn, null)));
    }

    @Override
    public String getDatabaseName(Long dataSourceConfigId) {
        return execute(dataSourceConfigId, conn -> {
            try (Statement st = conn.createStatement(); ResultSet rs = st.executeQuery("SELECT DATABASE()")) {
                rs.next();
                return rs.getString(1);
            }
        });
    }

    private <T> T execute(Long dataSourceConfigId, SqlFunction<Connection, T> action) {
        try (Connection conn = dataSourceConfigService.openConnection(dataSourceConfigId)) {
            return action.apply(conn);
        } catch (SQLException e) {
            throw exception(DATA_SOURCE_CONFIG_NOT_OK);
        }
    }

    @FunctionalInterface
    private interface SqlFunction<A, R> {
        R apply(A a) throws SQLException;
    }
}
```

```java
package com.ccloud.module.infra.service.codegen.inner;

/**
 * 由数据库表结构推断代码生成的默认定义。只做推断，不访问数据库，便于单测
 */
@Component
public class CodegenBuilder {

    public static final Set<String> BASE_COLUMNS =
            Set.of("creator", "create_time", "updater", "update_time", "deleted", "tenant_id");

    static final String DEFAULT_AUTHOR = "ccloud";
    /**
     * 本项目不做前端，前端类型固定为 0
     */
    static final int FRONT_TYPE_NONE = 0;

    private static final Map<String, String> JAVA_TYPES = Map.ofEntries(
            Map.entry("bigint", "Long"),
            Map.entry("int", "Integer"), Map.entry("integer", "Integer"), Map.entry("mediumint", "Integer"),
            Map.entry("smallint", "Integer"), Map.entry("tinyint", "Integer"),
            Map.entry("bit", "Boolean"),
            Map.entry("decimal", "BigDecimal"), Map.entry("numeric", "BigDecimal"),
            Map.entry("float", "Float"), Map.entry("double", "Double"),
            Map.entry("datetime", "LocalDateTime"), Map.entry("timestamp", "LocalDateTime"),
            Map.entry("date", "LocalDate"), Map.entry("time", "LocalTime"),
            Map.entry("char", "String"), Map.entry("varchar", "String"), Map.entry("tinytext", "String"),
            Map.entry("text", "String"), Map.entry("mediumtext", "String"), Map.entry("longtext", "String"),
            Map.entry("json", "String"));

    public CodegenTableDO buildTable(Long dataSourceConfigId, TableInfo table) {
        String[] parts = table.name().split("_", 2);
        if (parts.length < 2 || StrUtil.isBlank(parts[0]) || StrUtil.isBlank(parts[1])) {
            throw exception(CODEGEN_TABLE_NAME_INVALID);
        }
        if (StrUtil.isBlank(table.comment())) {
            throw exception(CODEGEN_TABLE_INFO_TABLE_COMMENT_IS_NULL);
        }
        String rest = parts[1].toLowerCase(Locale.ROOT);
        return new CodegenTableDO().setDataSourceConfigId(dataSourceConfigId)
                .setScene(CodegenSceneEnum.ADMIN.getScene()).setTemplateType(CodegenTemplateTypeEnum.ONE.getType())
                .setFrontType(FRONT_TYPE_NONE).setAuthor(DEFAULT_AUTHOR)
                .setTableName(table.name()).setTableComment(table.comment())
                .setModuleName(parts[0].toLowerCase(Locale.ROOT))
                .setBusinessName(StrUtil.subBefore(rest, "_", false))
                .setClassName(StrUtil.upperFirst(StrUtil.toCamelCase(rest)))
                .setClassComment(toClassComment(table.comment()));
    }

    /**
     * "积分记录表，按用户分表" → "积分记录"：取第一个分隔符前的部分，再去掉结尾的"表"
     */
    static String toClassComment(String comment) {
        String head = comment.trim().split("[，,（(：:；;。]", 2)[0].trim();
        return StrUtil.blankToDefault(StrUtil.removeSuffix(head, "表"), head);
    }

    public List<CodegenColumnDO> buildColumns(Long tableId, List<ColumnInfo> columns) {
        List<ColumnInfo> pks = columns.stream().filter(ColumnInfo::primaryKey).toList();
        if (pks.size() != 1 || !pks.get(0).autoIncrement() || !"Long".equals(javaType(pks.get(0)))) {
            throw exception(CODEGEN_PRIMARY_KEY_REQUIRED);
        }
        List<CodegenColumnDO> result = new ArrayList<>(columns.size());
        for (ColumnInfo column : columns) {
            if (StrUtil.isBlank(column.comment())) {
                throw exception(CODEGEN_TABLE_INFO_COLUMN_COMMENT_IS_NULL, column.name());
            }
            String javaType = javaType(column);
            if (javaType == null) {
                throw exception(CODEGEN_COLUMN_TYPE_UNSUPPORTED, column.name(), column.columnType());
            }
            boolean base = BASE_COLUMNS.contains(column.name());
            boolean editable = !column.primaryKey() && !base;
            String condition = defaultCondition(column, javaType);
            result.add(new CodegenColumnDO().setTableId(tableId).setColumnName(column.name())
                    .setDataType(column.columnType()).setColumnComment(column.comment())
                    .setNullable(column.nullable()).setPrimaryKey(column.primaryKey())
                    .setOrdinalPosition(column.ordinalPosition()).setJavaType(javaType)
                    .setJavaField(StrUtil.toCamelCase(column.name())).setDictType("")
                    .setCreateOperation(editable).setUpdateOperation(editable)
                    .setListOperation(condition != null)
                    .setListOperationCondition(condition != null ? condition : CodegenColumnListConditionEnum.EQ.getCondition())
                    .setListOperationResult(!base || "create_time".equals(column.name()))
                    .setHtmlType(defaultHtmlType(column, javaType)));
        }
        return result;
    }

    public static String javaType(ColumnInfo column) {
        return JAVA_TYPES.get(column.dataType());
    }

    /**
     * @return 默认作为查询条件时的比较方式；不作为查询条件返回 null
     */
    private static String defaultCondition(ColumnInfo column, String javaType) {
        String name = column.name();
        if ("create_time".equals(name)) {
            return CodegenColumnListConditionEnum.BETWEEN.getCondition();
        }
        if (column.primaryKey() || BASE_COLUMNS.contains(name)) {
            return null;
        }
        if ("String".equals(javaType) && (name.equals("name") || name.endsWith("_name") || name.equals("title"))) {
            return CodegenColumnListConditionEnum.LIKE.getCondition();
        }
        if (name.equals("status") || name.endsWith("_status") || name.equals("type") || name.endsWith("_type")
                || name.equals("sex")) {
            return CodegenColumnListConditionEnum.EQ.getCondition();
        }
        return null;
    }

    private static String defaultHtmlType(ColumnInfo column, String javaType) {
        return switch (javaType) {
            case "LocalDateTime", "LocalDate", "LocalTime" -> CodegenColumnHtmlTypeEnum.DATETIME.getType();
            case "Boolean" -> CodegenColumnHtmlTypeEnum.RADIO.getType();
            case "String" -> column.charMaxLength() == null || column.charMaxLength() > 500
                    ? CodegenColumnHtmlTypeEnum.TEXTAREA.getType() : CodegenColumnHtmlTypeEnum.INPUT.getType();
            default -> column.name().matches(".*(status|type|sex)$")
                    ? CodegenColumnHtmlTypeEnum.SELECT.getType() : CodegenColumnHtmlTypeEnum.INPUT.getType();
        };
    }
}
```

```java
    @Override
    @Transactional(rollbackFor = Exception.class)
    public List<Long> createCodegenList(Long dataSourceConfigId, List<String> tableNames) {
        if (dataSourceConfigService.getDataSourceConfig(dataSourceConfigId) == null) {
            throw exception(DATA_SOURCE_CONFIG_NOT_EXISTS);
        }
        List<Long> ids = new ArrayList<>(tableNames.size());
        for (String tableName : tableNames) {
            if (codegenTableMapper.selectByDataSourceConfigIdAndTableName(dataSourceConfigId, tableName) != null) {
                throw exception(CODEGEN_TABLE_EXISTS);
            }
            TableInfo tableInfo = databaseTableService.getTable(dataSourceConfigId, tableName);
            if (tableInfo == null) {
                throw exception(CODEGEN_IMPORT_TABLE_NULL);
            }
            CodegenTableDO table = codegenBuilder.buildTable(dataSourceConfigId, tableInfo);
            codegenTableMapper.insert(table);
            codegenColumnMapper.insertBatch(codegenBuilder.buildColumns(table.getId(), tableInfo.columns()));
            ids.add(table.getId());
        }
        return ids;
    }

    @Override
    @Transactional(rollbackFor = Exception.class)
    public void syncCodegenFromDB(Long tableId) {
        CodegenTableDO table = validateCodegenTableExists(tableId);
        TableInfo tableInfo = databaseTableService.getTable(table.getDataSourceConfigId(), table.getTableName());
        if (tableInfo == null) {
            throw exception(CODEGEN_IMPORT_TABLE_NULL);
        }
        Map<String, CodegenColumnDO> latest = CollectionUtils.convertMap(
                codegenBuilder.buildColumns(tableId, tableInfo.columns()), CodegenColumnDO::getColumnName);
        Map<String, CodegenColumnDO> current = CollectionUtils.convertMap(
                codegenColumnMapper.selectListByTableId(tableId), CodegenColumnDO::getColumnName);

        List<CodegenColumnDO> inserts = latest.values().stream().filter(c -> !current.containsKey(c.getColumnName())).toList();
        List<Long> deletes = current.values().stream().filter(c -> !latest.containsKey(c.getColumnName()))
                .map(CodegenColumnDO::getId).toList();
        // 只更新来自数据库的属性，用户在生成配置里的编辑（用途、字典、示例等）保留
        List<CodegenColumnDO> updates = new ArrayList<>();
        latest.values().stream().filter(c -> current.containsKey(c.getColumnName())).forEach(c -> {
            CodegenColumnDO old = current.get(c.getColumnName());
            if (!Objects.equals(old.getDataType(), c.getDataType()) || !Objects.equals(old.getColumnComment(), c.getColumnComment())
                    || !Objects.equals(old.getNullable(), c.getNullable()) || !Objects.equals(old.getPrimaryKey(), c.getPrimaryKey())
                    || !Objects.equals(old.getOrdinalPosition(), c.getOrdinalPosition())) {
                updates.add(new CodegenColumnDO().setId(old.getId()).setDataType(c.getDataType())
                        .setColumnComment(c.getColumnComment()).setNullable(c.getNullable())
                        .setPrimaryKey(c.getPrimaryKey()).setOrdinalPosition(c.getOrdinalPosition())
                        .setJavaType(c.getJavaType()));
            }
        });
        if (inserts.isEmpty() && deletes.isEmpty() && updates.isEmpty()) {
            throw exception(CODEGEN_SYNC_NONE_CHANGE);
        }
        if (!inserts.isEmpty()) {
            codegenColumnMapper.insertBatch(inserts);
        }
        if (!deletes.isEmpty()) {
            codegenColumnMapper.deleteByIds(deletes);
        }
        updates.forEach(codegenColumnMapper::updateById);
        codegenTableMapper.updateById(new CodegenTableDO().setId(tableId).setTableComment(tableInfo.comment()));
    }
```

```java
package com.ccloud.module.infra.service.codegen.inner;

/**
 * 模板使用的字段视图：把"怎么写成代码"的判断集中在这里，模板里只做拼接
 */
@Getter
public class CodegenColumnView {

    private final String columnName;
    private final String javaType;
    private final String javaField;
    private final String javaFieldUpper;
    /** 用于 Java 字符串字面量，已转义 */
    private final String comment;
    /** 用于 Javadoc，已去掉注释结束符 */
    private final String javadoc;
    /** 用于校验提示，取注释第一个分隔符前的部分，已转义 */
    private final String label;
    private final boolean primaryKey;
    private final boolean nullable;
    private final boolean string;
    private final boolean bigDecimal;
    private final boolean between;
    /** 时间类字段的格式，其他类型为 null */
    private final String dateTimePattern;
    private final String queryMethod;
    /** 为空串时为 null，模板用 #if 判断 */
    private final String dictType;
    private final String example;
    /** 字符类型的最大长度，由 dataType（如 varchar(100)）解析，其他为 null */
    private final Integer maxLength;
    /** 生成测试中的样例值（Java 表达式） */
    private final String sampleValue;

    public CodegenColumnView(CodegenColumnDO column, boolean treeParent) {
        this.columnName = column.getColumnName();
        this.javaType = column.getJavaType();
        this.javaField = column.getJavaField();
        this.javaFieldUpper = StrUtil.upperFirst(column.getJavaField());
        this.comment = escapeJava(column.getColumnComment());
        this.javadoc = column.getColumnComment().replace("*/", "* /");
        this.label = escapeJava(column.getColumnComment().trim().split("[，,（(：:；;。]", 2)[0].trim());
        this.primaryKey = Boolean.TRUE.equals(column.getPrimaryKey());
        this.nullable = Boolean.TRUE.equals(column.getNullable());
        this.string = "String".equals(javaType);
        this.bigDecimal = "BigDecimal".equals(javaType);
        this.between = CodegenColumnListConditionEnum.BETWEEN.getCondition().equals(column.getListOperationCondition());
        this.dateTimePattern = switch (javaType) {
            case "LocalDateTime" -> "yyyy-MM-dd HH:mm:ss";
            case "LocalDate" -> "yyyy-MM-dd";
            case "LocalTime" -> "HH:mm:ss";
            default -> null;
        };
        this.queryMethod = CodegenColumnListConditionEnum.valueOfCondition(column.getListOperationCondition()).getQueryMethod();
        this.dictType = StrUtil.emptyToNull(column.getDictType());
        this.example = StrUtil.isEmpty(column.getExample()) ? null : escapeJava(column.getExample());
        this.maxLength = parseLength(column.getDataType());
        this.sampleValue = treeParent ? "0L" : sampleValue(javaType, column.getDataType(), maxLength);
    }

    static String escapeJava(String text) {
        return text.replace("\\", "\\\\").replace("\"", "\\\"").replace("\r", " ").replace("\n", " ");

    private static Integer parseLength(String dataType) {
```

```java
    public Map<String, String> execute(CodegenTableDO table, List<CodegenColumnDO> columns) {
        Map<String, Object> context = buildContext(table, columns);
        Map<String, String> templates = templatePaths(table, context);
        Map<String, String> result = new LinkedHashMap<>();
        templates.forEach((template, path) -> {
            StringWriter writer = new StringWriter();
            velocity.getTemplate(template, StandardCharsets.UTF_8.name()).merge(new VelocityContext(new HashMap<>(context)), writer);
            result.put(path, writer.toString());
        });
        return result;
```

```java
package com.ccloud.module.infra.service.codegen;

/**
 * 供 scripts/verify-codegen.sh 使用：把两张演示表的生成结果写到环境变量 CCLOUD_CODEGEN_OUTPUT 指定的目录。
 * 未设置该变量时跳过，不参与日常测试

@EnabledIfEnvironmentVariable(named = "CCLOUD_CODEGEN_OUTPUT", matches = ".+")

    @Resource

    @Test
    void 生成两张演示表的代码() throws IOException {
        Path output = Path.of(System.getenv("CCLOUD_CODEGEN_OUTPUT"));
        Long studentId = codegenService.createCodegenList(0L, List.of("infra_demo_student")).get(0);
        Long categoryId = codegenService.createCodegenList(0L, List.of("infra_demo_category")).get(0);

        // 分类表：用户 App 场景的树表
        CodegenTableDO category = codegenService.getCodegenTable(categoryId);
        List<CodegenColumnDO> columns = codegenService.getCodegenColumnListByTableId(categoryId);
        CodegenUpdateReqVO reqVO = new CodegenUpdateReqVO();
        CodegenTableSaveReqVO table = BeanUtils.toBean(category, CodegenTableSaveReqVO.class);
        table.setScene(CodegenSceneEnum.APP.getScene());
        table.setTemplateType(CodegenTemplateTypeEnum.TREE.getType());
        table.setTreeParentColumnId(findId(columns, "parent_id"));
        table.setTreeNameColumnId(findId(columns, "name"));
        reqVO.setTable(table);
        reqVO.setColumns(BeanUtils.toBean(columns, CodegenColumnSaveReqVO.class));
        codegenService.updateCodegen(reqVO);

        int count = 0;
        for (Long tableId : List.of(studentId, categoryId)) {
            for (Map.Entry<String, String> file : codegenService.generationCodes(tableId).entrySet()) {
                Path target = output.resolve(file.getKey());
                Files.createDirectories(target.getParent());
                Files.writeString(target, file.getValue(), StandardCharsets.UTF_8);
                count++;
            }
        }
        assertThat(count).isEqualTo(22);
    }

    private static Long findId(List<CodegenColumnDO> columns, String name) {
        return columns.stream().filter(c -> c.getColumnName().equals(name)).findFirst().orElseThrow().getId();
    }
```

- [ ] **Step 1: 端到端验收脚本**

在 `verify-e2e.sh` 的"会员运营"之后、"文档、链路追踪、监控、定时任务"之前插入（`TMP` 用 `mktemp -d`，脚本退出时删除；本节开头 `AT=$(admin_login admin admin123 | jq -r '.data.accessToken')`，`AUTH="Authorization: Bearer $AT"`）：

```bash
echo "==> 基础设施"
TMP=$(mktemp -d); trap 'rm -rf "$TMP"' EXIT
AT=$(admin_login admin admin123 | jq -r '.data.accessToken')
AUTH="Authorization: Bearer $AT"
update_config() {  # $1=编号 $2=名称 $3=键 $4=值 $5=是否可见
  curl -s -X PUT "$GW/admin-api/infra/config/update" -H "$AUTH" -H "$JSON" \
    -d "{\"id\":$1,\"category\":\"biz\",\"name\":\"$2\",\"key\":\"$3\",\"value\":\"$4\",\"visible\":$5}" | jq -r '.code'
}
delete_admin_user() {  # $1=账号
  local id
  id=$(curl -s "$GW/admin-api/system/user/page?pageNo=1&pageSize=1&username=$1" -H "$AUTH" | jq -r '.data.list[0].id // empty')
  if [ -n "$id" ]; then curl -s -X DELETE "$GW/admin-api/system/user/delete?id=$id" -H "$AUTH" >/dev/null; fi
}

# 参数配置：导入用户使用参数中的初始密码
for u in demo01 demo02; do delete_admin_user "$u"; done
INIT_PW="E2e$(date +%s)"
[ "$(update_config 1 '用户管理-账号初始密码' system.user.init-password "$INIT_PW" false)" = "0" ] || die "修改初始密码参数失败"
curl -s "$GW/admin-api/system/user/get-import-template" -H "$AUTH" -o "$TMP/users.xls"
curl -s -X POST "$GW/admin-api/system/user/import" -H "$AUTH" -F "file=@$TMP/users.xls" \
  | jq -e '.data.createUsernames | index("demo01")' >/dev/null || die "导入用户失败"
[ -n "$(admin_login demo01 "$INIT_PW" | jq -r '.data.accessToken // empty')" ] || die "导入的用户不能用参数中的初始密码登录"
ok "导入用户使用参数配置中的初始密码"
update_config 1 '用户管理-账号初始密码' system.user.init-password 123456 false >/dev/null
for u in demo01 demo02; do delete_admin_user "$u"; done

# 参数配置：注册开关
REG="e2e_reg_$(date +%s)"
register() { curl -s -X POST "$GW/admin-api/system/auth/register" -H "$JSON" -H "$TENANT" \
  -d "{\"username\":\"$1\",\"nickname\":\"e2e\",\"password\":\"E2e123456\"}" | jq -r '.code'; }
[ "$(update_config 2 '管理后台-是否开放注册' system.auth.register-enabled true true)" = "0" ] || die "打开注册开关失败"
[ "$(register "$REG")" = "0" ] || die "注册开关打开后注册失败"
update_config 2 '管理后台-是否开放注册' system.auth.register-enabled false true >/dev/null
[ "$(register "${REG}x")" = "1001000010" ] || die "注册开关关闭后仍可注册"
delete_admin_user "$REG"
ok "注册开关由参数配置控制"

# 文件：上传、免登录读取、类型拦截、头像
python3 -c "import base64,sys; sys.stdout.buffer.write(base64.b64decode('iVBORw0KGgoAAAANSUhEUgAAAAEAAAABCAYAAAAfFcSJAAAADUlEQVR42mNkYPhfDwAChwGA60e6kgAAAABJRU5ErkJggg=='))" > "$TMP/a.png"
printf '<svg xmlns="http://www.w3.org/2000/svg"><script>alert(1)</script></svg>' > "$TMP/a.svg"
URL=$(curl -s -X POST "$GW/admin-api/infra/file/upload" -H "$AUTH" -F "file=@$TMP/a.png" | jq -r '.data // empty')
[ -n "$URL" ] || die "管理端上传文件失败"
curl -s -D "$TMP/h" -o "$TMP/b.png" "$URL"
cmp -s "$TMP/a.png" "$TMP/b.png" || die "免登录读取的内容与上传的不一致：$URL"
grep -qi '^x-content-type-options: nosniff' "$TMP/h" || die "文件读取缺少 nosniff 头"
ok "上传文件并免登录读取"
R=$(curl -s -X POST "$GW/admin-api/infra/file/upload" -H "$AUTH" -F "file=@$TMP/a.svg;filename=a.png" | jq -r '.code')
[ "$R" = "1002007001" ] || die "SVG 改名后上传返回 $R，期望被拒绝"; ok "SVG 改名上传被拒绝"
R=$(curl -s -X POST "$GW/app-api/infra/file/upload" -H "Authorization: Bearer $MT" -F "file=@$TMP/a.png" | jq -r '.code')
[ "$R" = "0" ] || die "会员上传文件返回 $R"; ok "会员上传文件"
AVATAR=$(curl -s -X PUT "$GW/admin-api/system/user/profile/update-avatar" -H "$AUTH" -F "avatarFile=@$TMP/a.png" | jq -r '.data // empty')
[ -n "$AVATAR" ] && [ "$(curl -s "$GW/admin-api/system/user/profile/get" -H "$AUTH" | jq -r '.data.avatar')" = "$AVATAR" ] \
  || die "管理员上传头像失败"
AVATAR=$(curl -s -X PUT "$GW/app-api/member/user/update-avatar" -H "Authorization: Bearer $MT" -F "avatarFile=@$TMP/a.png" | jq -r '.data // empty')
[ -n "$AVATAR" ] && [ "$(curl -s "$GW/app-api/member/user/get" -H "Authorization: Bearer $MT" | jq -r '.data.avatar')" = "$AVATAR" ] \
  || die "会员上传头像失败"
ok "管理员与会员上传头像"

# 文件：S3 兼容存储（本机 MinIO，容器经 host.docker.internal 访问）
CFG=$(curl -s -X POST "$GW/admin-api/infra/file-config/create" -H "$AUTH" -H "$JSON" -d "{\"name\":\"E2E-MinIO\",\"storage\":20,\"config\":{
  \"endpoint\":\"http://host.docker.internal:9000\",\"bucket\":\"ccloud\",\"accessKey\":\"$MINIO_ACCESS_KEY\",
  \"accessSecret\":\"$MINIO_SECRET_KEY\",\"pathStyle\":true,\"domain\":\"http://127.0.0.1:9000/ccloud\"}}" | jq -r '.data // empty')
[ -n "$CFG" ] || die "创建 MinIO 文件配置失败"
S3_URL=$(curl -s "$GW/admin-api/infra/file-config/test?id=$CFG" -H "$AUTH" | jq -r '.data // empty')
curl -s "$S3_URL" | grep -q 'ccloud' || die "MinIO 测试文件无法读取：$S3_URL"
curl -s "$GW/admin-api/infra/file-config/get?id=$CFG" -H "$AUTH" | jq -e '.data.config.accessSecret == "******"' >/dev/null \
  || die "文件配置返回了明文密钥"
curl -s -X DELETE "$GW/admin-api/infra/file-config/delete?id=$CFG" -H "$AUTH" >/dev/null
ok "S3 兼容存储（MinIO）上传与公开读取，密钥不回显"

# API 日志：登录请求已记录且密码已脱敏
deadline=$((SECONDS + 60))
until LOG=$(curl -s "$GW/admin-api/infra/api-access-log/page?pageNo=1&pageSize=1&applicationName=ccloud-system-server&requestUrl=/admin-api/system/auth/login" -H "$AUTH") \
      && [ "$(echo "$LOG" | jq -r '.data.total // 0')" -gt 0 ]; do
  [ $SECONDS -lt $deadline ] || die "60 秒内未查到登录接口的访问日志"
  sleep 3
done
PARAMS=$(echo "$LOG" | jq -r '.data.list[0].requestParams')
echo "$PARAMS" | grep -q 'admin123' && die "访问日志中出现了明文密码"
echo "$PARAMS" | grep -q '\*\*\*\*\*\*' || die "访问日志中的密码未替换为掩码：$PARAMS"
ok "其他服务的访问日志经消息流写入 infra，密码已脱敏"
redis_cli() { docker exec "$REDIS_CONTAINER" redis-cli --no-auth-warning -a "$REDIS_PASSWORD" -n "$REDIS_DATABASE" "$@"; }
ERR_APP="e2e-$(date +%s)"
redis_cli XADD ccloud:stream:infra.api-error-log '*' messageId "$ERR_APP" \
  payload "{\"applicationName\":\"$ERR_APP\",\"tenantId\":1,\"exceptionName\":\"java.lang.IllegalStateException\"}" >/dev/null
deadline=$((SECONDS + 30))
until ERR_ID=$(curl -s "$GW/admin-api/infra/api-error-log/page?pageNo=1&pageSize=1&applicationName=$ERR_APP" -H "$AUTH" \
      | jq -r '.data.list[0].id // empty') && [ -n "$ERR_ID" ]; do
  [ $SECONDS -lt $deadline ] || die "30 秒内未查到异常日志"
  sleep 3
done
R=$(curl -s -X PUT "$GW/admin-api/infra/api-error-log/update-status?id=$ERR_ID&processStatus=1" -H "$AUTH" | jq -r '.code')
[ "$R" = "0" ] || die "标记异常日志为已处理返回 $R"; ok "异常日志消费写库并可处理"

# 数据源、数据库文档、代码生成
curl -s "$GW/admin-api/infra/data-source-config/list" -H "$AUTH" | jq -e '.data[0].id == 0' >/dev/null || die "数据源列表首位不是主数据源"
R=$(curl -s -X POST "$GW/admin-api/infra/data-source-config/create" -H "$AUTH" -H "$JSON" \
  -d '{"name":"E2E","url":"jdbc:mysql://host.docker.internal:3306/ccloud","username":"root","password":"wrong-password"}' | jq -r '.code')
[ "$R" = "1002003001" ] || die "连不上的数据源返回 $R，期望拒绝保存"; ok "数据源保存前测试连接"
curl -s -D "$TMP/h" "$GW/admin-api/infra/db-doc/export-html" -H "$AUTH" -o "$TMP/doc.html"
grep -q 'infra_demo_student' "$TMP/doc.html" && grep -qi "^content-security-policy: default-src 'none'" "$TMP/h" \
  || die "数据库文档内容或安全头不正确"; ok "数据库文档导出"
TID=$(curl -s -X POST "$GW/admin-api/infra/codegen/create-list" -H "$AUTH" -H "$JSON" \
  -d '{"dataSourceConfigId":0,"tableNames":["infra_demo_student"]}' | jq -r '.data[0] // empty')
[ -n "$TID" ] || die "代码生成导入演示表失败（若上次运行中断，先在管理端删除已导入的 infra_demo_student）"
N=$(curl -s "$GW/admin-api/infra/codegen/preview?tableId=$TID" -H "$AUTH" | jq -r '.data | length')
curl -s -X DELETE "$GW/admin-api/infra/codegen/delete?tableId=$TID" -H "$AUTH" >/dev/null
[ "$N" = "11" ] || die "代码生成预览文件数为 $N，期望 11"; ok "代码生成导入与预览"

# 消息死信：重新投递到原主题
MID="e2e-dead-$(date +%s)"
lq "INSERT INTO ccloud.infra_message_dead_letter (message_id, topic, payload, retry_count, error_msg, handled, tenant_id)
    VALUES ('$MID', 'e2e.topic', '{\"a\":1}', 5, 'e2e', b'0', 1);" >/dev/null
DLID=$(lq "SELECT id FROM ccloud.infra_message_dead_letter WHERE message_id='$MID';")
R=$(curl -s -X PUT "$GW/admin-api/infra/message-dead-letter/resend?id=$DLID" -H "$AUTH" | jq -r '.code')
[ "$R" = "0" ] || die "死信重新投递返回 $R"
redis_cli XRANGE ccloud:stream:e2e.topic - + | grep -q "$MID" || die "死信未投递到原主题的消息流"
[ "$(lq "SELECT handled FROM ccloud.infra_message_dead_letter WHERE id=$DLID;")" = "1" ] || die "重新投递后死信未标记为已处理"
redis_cli DEL ccloud:stream:e2e.topic >/dev/null
lq "DELETE FROM ccloud.infra_message_dead_letter WHERE id=$DLID;" >/dev/null
ok "死信重新投递并标记为已处理"
```

说明：
- `lq` 查询 `bit(1)` 列时输出可能是 `1` 或二进制字符，若比较失败改为 `SELECT handled+0 ...`；
- `REDIS_CONTAINER`、`REDIS_PASSWORD`、`REDIS_DATABASE`、`MINIO_*` 由 `scripts/lib/local-middleware.sh` 提供；
- 用户导入模板里的部门编号须在演示数据中存在；导入失败时先检查 `failureUsernames` 的原因。
